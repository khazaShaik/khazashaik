Today I lead a team of four and own the architecture of an AI-powered test orchestration platform end to end, from LLM-driven test data generation to deterministic execution against SAP, APIs, and databases.

- Full stack by habit: Java and Spring Boot on the back end, Angular and React on the front, Python for AI services
- Building production AI: RAG pipelines, tool-calling agents, and multi-agent workflows with LangChain and LangGraph
